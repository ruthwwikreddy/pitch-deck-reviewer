# Pitch Deck Reviewer

A web tool to review PDF or PPTX pitch decks using local LLMs via Ollama. Ratings, summaries, and downloadable reports.

## Features
- Upload pitch decks (PDF/PPTX).
- AI-powered review with detailed ratings.
- Export feedback and reports as markdown.

## Running the App

1. Install dependencies:
    ```
    pip install -r requirements.txt
    ```

2. Run the app:
    ```
    streamlit run pitch_deck_reviewer.py
    ```

3. Deploy on Streamlit Cloud:
    Visit [Streamlit Cloud](https://streamlit.io/cloud) and deploy from [https://github.com/ruthwwikreddy/pitch-deck-reviewer](https://github.com/ruthwwikreddy/pitch-deck-reviewer).
